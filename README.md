# DBA Voice for Mac

株式会社DBA JapanのMac用音声入力アプリです。

製品ページ: https://dbajapan.com/dba-voice/

## 動作条件

- Apple Silicon搭載Mac（M1以降）
- macOS 26以降
- AIによる文章整理にはApple Intelligenceを有効にしてください。準備できていない場合は表記整理で動作します。

## インストール

1. 製品ページの「Mac版をダウンロード」からZIPを保存し、展開します。
2. DBA Voice.appを「アプリケーション」フォルダへ移動して開きます。
3. この先行配布版はApple未公証です。開発元を確認できないという警告で開けない場合は、開く操作の後に「システム設定 → プライバシーとセキュリティ → このまま開く」を選びます。Mac全体の保護機能を無効にする必要はありません。
4. アプリの案内に沿ってマイクとアクセシビリティを許可します。
5. 入力したい欄をクリックし、右Optionキーを押しながら話して、キーを離します。録音キーは設定でFnにも変更できます。

音声認識モデルWhisper large-v3-turboを同梱しています。追加で音声モデルをダウンロードする必要はありません。文字起こしと文章整理はMac内で行います。

初期設定は「AIで言い直しを整える」です。Apple Intelligenceを準備したMacで使用してください。設定画面の「文字起こし後の整え方」で現在の状態を確認できます。

## データと不具合への備え

原稿と復旧用音声はMac内で保存します。Supabaseへの利用状況の送信には、アプリ内でのログインと同意が必要です。文章の送信は別の選択項目で、初期設定ではオフです。音声をサーバーへ送信しません。

クラウドに送信していない文章や、保存期間を過ぎた文章をサーバーから復元することはできません。Mac故障時も含む全履歴の自動バックアップを保証するものではありません。

## 更新

この先行配布版は自動更新を行いません。新しい版は製品ページから入手してください。

同梱する第三者ソフトウェアと音声認識モデルのライセンスは、アプリ内Contents/Resources/Licensesに含みます。このリポジトリは配布ファイルと案内専用です。
