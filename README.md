# DBA Voice for Mac

株式会社DBA JapanのMac用音声入力アプリです。

製品ページ: https://dbajapan.com/dba-voice/

[画像付きの初回設定・Claude Code／Codex用プロンプト](https://dbajapan.com/dba-voice/setup/)

## 動作条件

- Apple Silicon搭載Mac（M1以降）
- macOS 26以降
- AIによる文章整理にはApple Intelligenceを有効にしてください。準備できていない場合は表記整理で動作します。

## インストール

1. 製品ページの「Mac版をダウンロード」から軽量版「DBA-Voice-Mac.tar.xz」を保存し、ダブルクリックして開きます。Mac標準の機能で展開できます。展開には時間がかかる場合があります。
2. DBA Voice.appを「アプリケーション」フォルダへ移動し、開きます。
3. この先行配布版はApple未公証です。「開いていません」「マルウェアが含まれていないことを検証できませんでした」と表示された場合は「完了」を押します。警告が出た同じMacで「システム設定 → プライバシーとセキュリティ」の「セキュリティ」欄へ進みます。DBA Voiceがブロックされたという説明の横にある「開く」または「このまま開く」を押し、続く確認に従います。パスワードやTouch IDは本人が入力します。Mac全体の保護機能を無効にする必要はありません。
4. アプリの案内に沿ってマイクとアクセシビリティを許可します。
5. 入力したい欄をクリックし、右Optionキーを押しながら話して、キーを離します。録音キーは設定でFnにも変更できます。

音声認識モデルWhisper large-v3-turboを同梱しています。追加で音声モデルをダウンロードする必要はありません。文字起こしと文章整理はMac内で行います。

軽量版は約1.34 GBで、従来のZIP版約1.50 GBから約10.3%小さくなりました。展開後のアプリと音声認識モデルは同じです。変更したのは圧縮方法だけで、能力・機能・インストール後の容量は変わりません。強く圧縮しているため、展開はZIP版より時間がかかります。従来のZIP版も製品ページから選べます。

取得済みのZIP・DMG・展開済みアプリは、そのまま使えます。取り直す必要はありません。DMG版は約1.43 GBで、DMGを開き、DBA Voice.appを隣の「Applications」へドラッグして配置します。

許可ボタンが出ない場合は、操作しているMacが警告の出たMacかを確認してください。ボタンは起動を試みてから約1時間だけ使用できます。同じMacでDBA Voiceをもう一度開き、実際の警告を確認してから設定へ戻ります。詳しくは[AppleのmacOS 26向け手順](https://support.apple.com/ja-jp/guide/mac-help/mh40617/26/mac/26)をご覧ください。

初期設定は「AIで言い直しを整える」です。Apple Intelligenceを準備したMacで使用してください。設定画面の「文字起こし後の整え方」で現在の状態を確認できます。

## データと不具合への備え

クラウドの新規登録は準備中です。Mac内の音声入力は、登録せずに使えます。

原稿と復旧用音声はMac内で保存します。Supabaseへの利用状況の送信には、アプリ内でのログインと同意が必要です。文章の送信は別の選択項目で、初期設定ではオフです。音声をサーバーへ送信しません。

送信済みの自分の文章は、保存から30日以内なら「アカウントとデータ → クラウドの文章を履歴に復元」で戻せます。既存の履歴を上書きしません。

クラウドに送信していない文章や、保存期間を過ぎた文章をサーバーから復元することはできません。Mac故障時も含む全履歴の自動バックアップを保証するものではありません。

## 更新

この先行配布版は自動更新を行いません。新しい版は製品ページから入手してください。

同梱する第三者ソフトウェアと音声認識モデルのライセンスは、アプリ内Contents/Resources/Licensesに含みます。このリポジトリは配布ファイルと案内専用です。
